# Reference style paradigms

Use these as layout grammars, not content templates. Select a paradigm from the relationships already present in the outline.

## 1. Visual + interpretation

Use when one image, chart, screenshot, or illustration is the main information object.

```text
RUNNING HEADER
Viewpoint title
────────────────────────────────────────
Dominant visual (≈65%)   Message group 1
                        Message group 2
                        Optional note
Caption / source when supplied
```

- Keep one dominant visual.
- Preserve its caption and source when they exist.
- Do not repeat the title as the first message.

## 2. Process

Use for dependent steps or state transitions.

```text
Viewpoint title

[Stage 1] ──> [Stage 2] ──> [Stage 3]
   detail        detail        detail

Optional annotation
```

- Keep the main path in one reading direction.
- Put detail near the stage it describes.
- Split the slide when more than three stages require dense explanation.

## 3. Highlight + support

Use when the outline contains one dominant phrase, number, quotation, or takeaway.

```text
Viewpoint title

Large highlight       Supporting text, comparison, or visual
short label           optional annotation

Optional note
```

- The highlight, title, and body must still use only the profile's three sizes.
- Reuse the title size for the highlight.
- Keep the highlight meaningful without decorative scale.

## 4. Aligned comparison

Use when alternatives share repeated fields.

```text
Viewpoint title

                 A              B              Interpretation
Field 1
Field 2
Field 3
Optional note
```

- Prefer thin rules over colored cells.
- Align equivalent fields on the same row.
- State non-comparability only when it exists in the source.

## 5. Two-column message

Use when two groups answer the same viewpoint from complementary angles.

```text
Viewpoint title

Left group                         Right group
message + detail                   message + detail
optional visual                    optional visual

Shared annotation
```

- Do not use two columns merely to fill space.
- Keep both columns visually balanced but not artificially equal.
- Split when each side needs its own conclusion.

## 6. Closing

Use when the outline contains a conclusion, action, question, or next step.

```text
Viewpoint title

Message 1
Message 2
Message 3

Final emphasized phrase
```

- Keep the background light under the default profile.
- Preserve only actions or conclusions present in the source.
- Use the final emphasized phrase as the main memory cue.
