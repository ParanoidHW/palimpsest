# Narrative Paper Review Checklist (v1.8)

Mark each item done, blocked or skipped-with-reason only after recording the indicated evidence. This is a process record; do not copy the list into the Paper.

## Source and ownership

- [pending] S1 Canonical identity and coverage matrix checked; source version, domain, slug, owner and operation recorded.
- [pending] S2 PDF or official source acquired and version locked; authorship/affiliations checked against source markers.
- [pending] S3 Code, checkpoint/config and public review evidence checked or availability precisely classified.

## Narrative and evidence

- [pending] N1 Each source subsection summarized in working notes, then a causal reading path drafted before prose.
- [pending] N2 Opening shows the prior workflow, visible failure and consequence before method jargon.
- [pending] N3 Design choices, agent roles and state changes are explained at the point they matter.
- [pending] N4 Key equations appear near the claim they explain, with variables, units, assumptions and interpretation nearby.
- [pending] N5 Experimental setup, baseline, denominator and aggregation appear before the gains they qualify.
- [pending] N6 Original Figures/Tables have complete captions, tight crops, inventory entries, full-resolution QA and nearby interpretation.
- [pending] N7 Consequential claims trace to source sections/figures/tables/code; reviewer inference is identified.
- [pending] N8 Uncommon terms are defined on first use; unresolved evidence limits attach to their claims.

## Reading and publication

- [pending] R1 Rendered Markdown inspected for formulas, images, tables and navigation.
- [pending] R2 Human reading pass recorded with reviewer, report hash, three source-to-report checks and concrete findings/dispositions.
- [pending] R3 v1.8 manifest and deterministic validator pass with empty errors; machine result reported separately from human judgment.
- [pending] P1 Promotion-plan schema and publisher validator pass, or canonical publication explicitly blocked.
- [pending] P2 Formal links/assets tracked, no forbidden or orphan references, coverage matrix updated when Paper changes.
- [pending] P3 Only task files staged; local Git commit created unless user explicitly asked otherwise.
