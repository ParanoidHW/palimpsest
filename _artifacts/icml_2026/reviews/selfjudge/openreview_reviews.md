# OpenReview public-review check

- Paper: SelfJudge: Faster Speculative Decoding via Self-Supervised Judge Verification
- arXiv: https://arxiv.org/abs/2510.02329v2
- Access date: 2026-07-17 (Asia/Shanghai)
- Search result: no public OpenReview forum/review was located for this paper. The arXiv metadata records `journal_ref: ICML 2026`, but neither the arXiv page nor the supplied source package exposes an OpenReview forum URL.
- Recovery attempts: queried `https://api2.openreview.net/notes` by exact title (HTTP 403 in the restricted environment); searched the paper PDF/source and arXiv metadata for `openreview.net` links (only references to prior work, no SelfJudge forum).

结论：公开评审、meta-review、decision、rebuttal 和 discussion 不可获得，因此不做 reviewer-claim 交叉核验；该限制不会改变对论文正文、附录和源包的证据判断，但会降低对审稿阶段未公开问题的覆盖。
