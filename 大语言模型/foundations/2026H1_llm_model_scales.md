## DeepSeek V3.2 规格补充

DeepSeek V3.2 发布时间为 2025-12，严格说不在本表 `2026-01-06 ~ 2026-07-06` 的半年窗口内，但经常被作为 2026 H1 对照模型引用。公开规格为 `671B total / 37B activated`；HF 权重 safetensors 统计约 `685.4B`，主权重为 FP8。结构上是 MoE，config 显示 61 层、256 routed experts、8 selected/token、最大上下文 163,840 tokens；Attn 类型为 DSA（DeepSeek Sparse Attention），config 为 128 attention heads / 128 KV heads。来源：[DeepSeek-V3.2](https://huggingface.co/deepseek-ai/DeepSeek-V3.2)、[DeepSeek-V4-Pro README 对照表](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro)。
